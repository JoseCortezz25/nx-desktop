Este proyecto, nx-desktop, es una base para crear una aplicación de escritorio con Tauri 2, React y TypeScript. Actualmente conserva la plantilla inicial; todavía no tiene funcionalidades de negocio que permitan identificar un propósito más específico.

Su estructura principal es:

  • Interfaz en React (src/): muestra una bienvenida y un formulario para escribir tu nombre.
  • Código nativo en Rust (src-tauri/): recibe ese nombre y devuelve un saludo.
  • Vite: sirve la interfaz durante el desarrollo y genera sus archivos de producción.
  • Tauri: integra la interfaz con Rust dentro de una ventana de escritorio.

La demostración actual sigue este flujo: escribes un nombre → React llama al comando greet de Rust → aparece el saludo. Puedes verlo en App.tsx y lib.rs.

Aunque se llama “nx-desktop”, el manifiesto revisado no incluye Nx como herramienta. El nombre, por sí solo, no indica una integración con ese sistema.
