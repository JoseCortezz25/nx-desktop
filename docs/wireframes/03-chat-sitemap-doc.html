Sitemap and interaction model

The project board and orchestrator conversation are the primary workspace. Specs aggregate tickets; execution detail belongs to the ticket rather than a separate execution navigation section.

Navigation

├── Home
│   ├── Project overview and active work
│   ├── Blockers and approval requests
│   └── Recent activity and consumption summary
├── Add project
│   ├── Select existing folder or create folder
│   ├── Choose native or WSL execution environment
│   └── Repository and tool diagnosis
├── Project workspace
│   ├── Board with spec grouping and filters
│   ├── Orchestrator conversation panel

│   │   └── Spec/ticket proposals and approvals

│   │   ├── Specification, criteria, dependencies, and origin

│   │   ├── Worktree, branch, and PR

│   └── Project settings
└── General settings
    ├── CLI tools: detection, prerequisite guidance, diagnosis
